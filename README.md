# Yustina Selezneva — Portfolio (final prototype)

Image-free bilingual RU/EN creative portfolio. The design intentionally uses typography, vector-like CSS geometry and information design instead of NDA-protected campaign visuals.

Open `index.html` locally in a browser. No build step or dependencies are required.

Files:
- `index.html` — structure/content
- `styles.css` — responsive art direction
- `script.js` — RU/EN switch and cursor interaction

NDA note: brand names are separated from anonymised case studies; project-specific visuals are not embedded.
